# Documentación heredada

Esta carpeta conserva documentos y evidencias históricas migrados del repositorio
original `TSP_PSPS`, en la versión `119ab3e` (29/10/2026). Se mantienen como
referencia del proceso, no como documentación vigente.

Pueden contener afirmaciones superadas por cambios posteriores. En particular, el
logro L-10 y la cifra de «once logros» fueron retirados por la adenda de
integración del 29/10/2026; el catálogo vigente tiene diez logros (L-01 a L-09 y
L-11). Las rutas `lib/...` que citan estos documentos corresponden a la estructura
anterior a la reorganización actual.

La documentación vigente está en `docs/`: consulta `docs/ARCHITECTURE.md` para la
arquitectura del código y `docs/audit/` para las decisiones, la trazabilidad y los
riesgos de la migración. Las evidencias del Sprint 1 se conservan en
`docs/legacy/evidencias_sprint1/`.
